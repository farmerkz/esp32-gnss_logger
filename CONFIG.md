# Руководство по конфигурации устройства (`config.json`)

Настоящий документ содержит подробное описание всех параметров конфигурации системы **ESP32 GNSS Logger & Wardriving**, с указанием их типов данных, допустимых значений, значений по умолчанию и поведения системы.

---

## 📁 Размещение файла конфигурации

Файл конфигурации считывается с SD-карты по пути:
```text
/sdcard/config.json
```

### Принцип работы и приоритеты (NVS Primary + SD Sync):
1. **Первоисточником конфигурации является NVS Flash** ESP32 с маркером валидности `APP_CONFIG_MAGIC`.
2. При включении питания система проверяет наличие валидной конфигурации в **NVS Flash**.
3. **При первом запуске (или пустой NVS Flash)**: конфигурация считывается из файла `/sdcard/config.json`, сохраняется в NVS Flash и устанавливается маркер валидности. Если файл на SD-карте отсутствует или повреждён — фиксируется **фатальная ошибка** и устройство перезагружается.
4. **При повторных запусках (валидная NVS существует)**: считывается файл `/sdcard/config.json` (если он есть). В случае наличия изменений конфигурация в NVS **полностью обновляется из файла**. Если файл на SD-карте отсутствует или некорректен — устройство продолжает работу на валидной конфигурации из NVS Flash.
5. Для работы всегда применяется конфигурация из NVS Flash с учетом значений по умолчанию для не заданных параметров.

## 🌐 Редактирование конфигурации через Веб-интерфейс

В веб-интерфейсе устройства на вкладке **⚙️ Конфигурация** реализован встроенный графический редактор параметров с соблюдением следующих правил безопасности и целостности:

1. **Отложенное применение и прямая привязка к файлу (Pending Reboot)**:
   - При открытии редактора текущие параметры считываются **напрямую из файла `/sdcard/config.json`**. Это гарантирует, что пользователь видит именно те настройки, которые фактически записаны на диске.
   - Сохранение из веб-интерфейса производится также **строго в файл `/sdcard/config.json`**.
   - Оперативная память (`g_app_config`) и NVS текущего сеанса работы **не изменяются**. Изменения вступят в силу только после перезагрузки устройства.
2. **Сохранение только не-дефолтных параметров**:
   - При сохранении файл `/sdcard/config.json` формируется автоматически: в него включаются **только те параметры, значения которых отличаются от значений по умолчанию**.
   - Параметры со значениями по умолчанию в файл не записываются для обеспечения минималистичности конфигурации.
3. **Резервное копирование (`/sdcard/config.json.bak`)**:
   - Перед перезаписью файла `/sdcard/config.json` предыдущая версия файла автоматически копируется в `/sdcard/config.json.bak` под защитой мьютекса `g_sd_mutex`.
4. **Защита Read-Only идентификаторов**:
   - Параметры `ssid`, `ftpaddress`, `ftpuser` и `webuser` выводятся в режиме только для чтения (`disabled`) и их невозможно изменить через веб-интерфейс. Бэкенд веб-сервера игнорирует и отвергает подмену данных полей.
5. **Маскирование и повторный ввод паролей**:
   - Пароли `wifipasswd`, `ftppassword` и `webpassword` отображаются маскированными (`••••••••`).
   - При вводе нового пароля запрашивается повторный ввод (подтверждение). Изменение принимается только при полном совпадении обоих полей.
6. **Индикация параметров по умолчанию**:
   - Параметры, совпадающие со значениями по умолчанию, снабжаются подписью `[По умолчанию]`.

## 🛠 Пример файла `config.json`

```json
{
  "ssid": "MyWiFiAP",
  "wifipasswd": "MySecretPassword",
  "ftpaddress": "192.168.1.100",
  "ftpuser": "ftpuser",
  "ftppassword": "ftppasswd",
  "ftpport": 21,
  "filesize": 1000000,
  "gpssend": true,
  "wifisend": true,
  "ftpbeep": true,
  "moduleid": "01",
  "pdopmask": 0,
  "paccmask": 0,
  "min_track_size": 1000
}
```

## 📋 Подробное описание параметров

### 1. Сетевые параметры Wi-Fi

| Параметр | Тип данных | Значение по умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `ssid` | `String` | `"ssid"` | Имя точки доступа Wi-Fi (SSID), к которой ESP32 подключается для передачи файлов по FTP. Максимальная длина — 31 символ. Поддерживаются сети WPA2-PSK и WPA3-SAE H2E. |
| `wifipasswd` | `String` | `"wifipassword"` | Пароль для аутентификации в сети Wi-Fi. Максимальная длина — 63 символа. |

---

### 2. Параметры подключения к FTP серверу

| Параметр | Тип данных | Значение по умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `ftpaddress` | `String` | `"192.168.168.100"` | IP-адрес (например, `"192.168.1.100"`) или доменное имя удаленного FTP сервера. Максимальная длина — 63 символа. |
| `ftpuser` | `String` | `"ftpuser"` | Имя пользователя (логин) для авторизации на FTP сервере. Максимальная длина — 31 символ. |
| `ftppassword` | `String` | `"ftppasswd"` | Пароль пользователя для авторизации на FTP сервере. Максимальная длина — 31 символ. |
| `ftpport` | `Integer` | `21` | Управляющий TCP-порт FTP сервера. Диапазон допустимых значений: `1` – `65535`. |

---

### 3. Настройки передачи данных и сигналов

| Параметр | Тип данных | Значение по умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `filesize` | `Integer` | `1000000` *(1 МБ)* | Пороговый размер активного файла лога Wi-Fi (Wigle CSV) в байтах. При достижении указанного размера файл ротируется (закрывается и перемещается из `.wk` в `.rd` для отгрузки по FTP). **Файлы с GPS треками (GPX) ограничиваются размером в 50 МБ.** Системный лог (`syslog.txt`) ограничен размером в 10 МБ. |
| `gpssend` | `Boolean` | `true` | Флаг разрешения отгрузки GPX файлов треков на FTP сервер. Если `true`, закрытые треки из `/sdcard/gps.rd` передаются на сервер. Если `false`, отгрузка GPX игнорируется. |
| `wifisend` | `Boolean` | `true` | Флаг разрешения отгрузки Wigle CSV файлов сканирования Wi-Fi на FTP сервер. Если `true`, закрытые логи из `/sdcard/wifi.rd` передаются на сервер. Если `false`, отгрузка Wi-Fi логов игнорируется. |
| `ftpbeep` | `Boolean` | `false` | Флаг включения звукового оповещения при успешной отгрузке файлов на FTP. При `true` после успешной выгрузки воспроизводится мажорный тритон. |
| `moduleid` | `String` | `"00"` | Уникальный двухсимвольный (или до 7 символов) идентификатор устройства. Добавляется к имени каждого выгружаемого файла на FTP сервере перед расширением (например, `gps-2026-07-27_070609-02.gpx`) во избежание конфликтов имен при работе нескольких логгеров. |

---

### 4. Фильтры качества данных GNSS (u-blox)

| Параметр | Тип данных | Значение по умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `pdopmask` | `Integer` | `0` | Пороговая маска PDOP (Position Dilution of Precision). Передается в модуль u-blox через команду `UBX-CFG-NAV5`. Значение задается умноженным на 10 (например, `25` соответствует PDOP 2.5). Если `0`, фильтрация по PDOP отключена. |
| `paccmask` | `Integer` | `0` | Пороговая маска горизонтальной точности Position Accuracy (PACC) в метрах. Передается в модуль u-blox через команду `UBX-CFG-NAV5`. Если `0`, фильтрация по PACC отключена. |
| `timezone` | `Integer` | `5` | Смещение системных часов от UTC в часах (например, `5` соответствует UTC+5, `-3` соответствует UTC-3). Используется для внутренней синхронизации времени микроконтроллера `settimeofday()`. Альтернативные имена ключа: `timezone_offset`, `tz`. |
| `min_track_size` | `Integer` | `1000` | Минимальный размер GPX или Wigle CSV файла в байтах. Файлы, не достигшие этого размера при запуске системы (после аварийного отключения), считаются «пустыми» и удаляются. Файлы, равные или больше этого размера, ремонтируются и переносятся в `.rd`. Альтернативное имя ключа: `mintracksize`. |

---

### 5. Параметры веб-сервера

| Параметр | Тип данных | Значение по умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `webserverenable` | `Boolean` | `false` | Флаг разрешения активации веб-сервера. Если `true` и заданы `webuser`/`webpassword`, устройство **подключается и поддерживает связь с Wi-Fi AP постоянно** (независимо от наличия файлов для FTP). Если `false`, подключение к AP выполняется **On-Demand (только при наличии файлов для FTP)**. Альтернативное имя ключа: `webserver_enable`. |
| `webuser` | `String` | `""` | Имя пользователя для HTTP Basic Auth авторизации в веб-интерфейсе. Альтернативное имя ключа: `webserver_user`. |
| `webpassword` | `String` | `""` | Пароль пользователя для HTTP Basic Auth авторизации в веб-интерфейсе. Альтернативное имя ключа: `webserver_passwd`. |
